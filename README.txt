VISUALS BY SHRRIYAS — FREE PORTFOLIO STARTER

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Install the free "Live Server" extension, or simply double-click index.html.
4. Edit index.html, style.css and script.js.

IMPORTANT CUSTOMISATIONS BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your real email.
2. Replace YOUR_USERNAME in Instagram and Behance links.
3. Replace 91XXXXXXXXXX in the WhatsApp link with your number (country code + number, digits only).
4. Replace the sample project art cards with your own poster images and video links.
5. The four colourful project cards are sample placeholders, NOT client work. Label your self-initiated work as "Concept Project".
6. Test all links and check the site on mobile.

FREE HOSTING WITH GITHUB PAGES
1. Create a free account at https://github.com/
2. Create a new public repository named visuals-by-shrriyas
3. Upload index.html, style.css, script.js and your assets folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. GitHub will provide your public website URL after deployment.

NOTES
- GitHub Pages supports static HTML, CSS and JavaScript sites.
- A custom domain is optional and costs extra; use the free github.io address.
- Google Fonts requires an internet connection. System fonts will be used if unavailable.
